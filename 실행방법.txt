========================================
Windows에서 실행하는 방법
========================================

방법 1: 가장 간단 (권장)
-----------------------
1. 이 파일들을 Windows로 다운로드
2. index.html 파일을 Chrome 브라우저로 드래그
3. 끝!


방법 2: 로컬 서버 사용
---------------------
1. 파일 다운로드
2. Windows PowerShell 열기
3. 다운로드한 폴더로 이동:
   cd 다운로드경로

4. 다음 중 하나 실행:

   Python이 있으면:
   python -m http.server 8080

   Node.js가 있으면:
   npx http-server -p 8080

5. 브라우저에서 열기:
   http://localhost:8080


사용 방법
---------
1. "시작하기" 버튼 클릭
2. 카메라 권한 허용
3. 얼굴을 카메라에 비추기
4. 감정 인식 시작!


문제 해결
---------
- 카메라 안 됨: 브라우저 설정에서 카메라 권한 확인
- 모델 로딩 실패: 인터넷 연결 확인
- 페이지 안 열림: Chrome 브라우저 사용
